## 🚀 Основні можливості

### 👥 Управління користувачами
- Автоматичне додавання нових користувачів
- Збереження налаштувань підписок
- Відстеження активності користувачів

### ⚙️ Персоналізація підписок
- **🚨 Тривоги** - повітряні тривоги
- **📰 Новини** - останні новини з українських джерел  
- **🕯️ Меморіальні** - важливі дати та події

### 🎛️ Способи налаштування
1. **Inline кнопки** - зручний інтерфейс через `/settings`
2. **Команди** - швидкі команди `/subscribe` та `/unsubscribe`
3. **Статус** - перевірка поточних налаштувань через `/status`

### 📊 Статистика та моніторинг
- Загальна кількість користувачів
- Кількість підписників на кожен тип
- Логування всіх дій

## 🔧 Технічна реалізація

### База даних
```json
{
  "123456789": {
    "user_id": 123456789,
    "username": "user123",
    "first_name": "User Name",
    "subscriptions": {
      "alerts": true,
      "news": false,
      "memorial": true
    },
    "created_at": "2024-01-01T12:00:00",
    "last_activity": "2024-01-01T12:00:00"
  }
}
```

### Команди бота
- `/start` - початок роботи
- `/help` - довідка
- `/settings` - налаштування через кнопки
- `/subscribe <type>` - підписка
- `/unsubscribe <type>` - відписка
- `/status` - поточні налаштування
- `/stats` - статистика

### Персоналізоване надсилання
```python
# Надсилання новини тільки підписникам
await bot.send_news_to_users(news_item, all_users)

# Надсилання тривоги тільки підписникам
await bot.send_alert_to_users(alert_message, all_users)

# Надсилання меморіального повідомлення тільки підписникам
await bot.send_memorial_to_users(memorial_message, all_users)
```
