# 🚀 Гід по налаштуванню Персоналізованого Telegram Бота

## 📋 Перед початком

### 1. Створення бота в Telegram

1. Відкрийте Telegram і знайдіть @BotFather
2. Надішліть команду `/newbot`
3. Введіть назву бота (наприклад: "Мій Персоналізований Бот")
4. Введіть username бота (наприклад: "my_personalized_bot")
5. Скопіюйте отриманий токен

### 2. Налаштування змінних середовища

Створіть файл `.env` в корені проекту:

```env
# Telegram налаштування
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# ID вашого каналу (опціонально)
CHANNEL_ID=@your_channel_name

# Токен для API повітряних тривог (опціонально)
ALERTS_API_TOKEN=your_alerts_api_token
```

## 🛠️ Встановлення

### 1. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 2. Перевірка встановлення

```bash
python test_personalized_bot_simple.py
```

Якщо бачите "🎉 Всі тести пройдені успішно!", то все встановлено правильно.

## 🚀 Запуск

### Швидкий запуск (Windows)

Подвійний клік на файл `run_personalized_bot.bat`

### Запуск через командний рядок

```bash
python main_personalized.py
```

## 📱 Використання бота

### Перший запуск

1. Знайдіть свого бота в Telegram
2. Натисніть `/start`
3. Бот автоматично додасть вас до бази користувачів

### Налаштування підписок

#### Через команду /settings

1. Натисніть `/settings`
2. Використовуйте кнопки для перемикання:
   - ✅ 🚨 Тривоги
   - ✅ 📰 Новини  
   - ✅ 🕯️ Меморіальні
3. Натисніть "💾 Зберегти"

#### Через команди

```bash
/subscribe alerts     # Підписатися на тривоги
/subscribe news       # Підписатися на новини
/subscribe memorial   # Підписатися на меморіальні
/subscribe all        # Підписатися на все

/unsubscribe alerts   # Відписатися від тривог
/unsubscribe news     # Відписатися від новин
/unsubscribe all      # Відписатися від всього
```

### Перевірка налаштувань

```bash
/status    # Показати поточні налаштування
/stats     # Статистика (для адміністраторів)
```

## 🔧 Налаштування для розробників

### Структура проекту

```
├── user_manager.py           # Управління користувачами
├── personalized_bot.py       # Персоналізований бот
├── main_personalized.py      # Основний файл
├── config.py                # Конфігурація
├── news_collector.py        # Збір новин
├── air_alerts_monitor.py    # Моніторинг тривог
├── memorial_messages.py     # Меморіальні повідомлення
├── users.json              # База даних користувачів
└── PERSONALIZATION_README.md # Документація
```

### Додавання нового типу повідомлень

1. Відредагуйте `user_manager.py`:
```python
'subscriptions': {
    'alerts': True,
    'news': True,
    'memorial': True,
    'new_type': True  # Додайте новий тип
}
```

2. Оновіть `personalized_bot.py`:
```python
sub_name = {
    'alerts': '🚨 Тривоги',
    'news': '📰 Новини',
    'memorial': '🕯️ Меморіальні',
    'new_type': '🆕 Новий тип'  # Додайте назву
}
```

3. Створіть метод надсилання в `personalized_bot.py`:
```python
async def send_new_type_to_users(self, message: str, user_ids: List[int]):
    return await self.send_personalized_message(
        user_ids=user_ids,
        message=message,
        subscription_type='new_type',
        parse_mode='HTML'
    )
```

## 🐛 Вирішення проблем

### Помилка "BOT_TOKEN не заданий"

1. Перевірте, чи створений файл `.env`
2. Переконайтеся, що токен введений правильно
3. Перезапустіть бота

### Помилка "ModuleNotFoundError"

```bash
pip install -r requirements.txt
```

### Бот не відповідає на команди

1. Перевірте, чи запущений бот
2. Переконайтеся, що токен правильний
3. Перевірте логи на помилки

### Повідомлення не надсилаються

1. Перевірте налаштування підписок: `/status`
2. Переконайтеся, що користувач активний
3. Перевірте логи на помилки надсилання

## 📊 Моніторинг

### Логи

Бот веде детальні логи всіх дій. Перевіряйте консоль для інформації про:
- Підключення користувачів
- Надсилання повідомлень
- Помилки та попередження

### Статистика

Команда `/stats` показує:
- Загальна кількість користувачів
- Кількість підписників на кожен тип

### База даних

Користувачі зберігаються в `users.json`:
```json
{
  "123456789": {
    "user_id": 123456789,
    "username": "user123",
    "subscriptions": {
      "alerts": true,
      "news": false,
      "memorial": true
    }
  }
}
```
