# 🤖 Персоналізований Telegram Бот

Цей бот дозволяє користувачам налаштовувати, які повідомлення вони хочуть отримувати: тривоги, новини або меморіальні повідомлення.

## ✨ Основні можливості

- 🚨 **Повітряні тривоги** - миттєві повідомлення про тривоги
- 📰 **Останні новини** - новини з українських джерел
- 🕯️ **Меморіальні повідомлення** - важливі дати та події
- ⚙️ **Персоналізація** - кожен користувач обирає, що отримувати
- 📊 **Статистика** - інформація про підписників

## 🚀 Запуск

### 1. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 2. Налаштування змінних середовища

Створіть файл `.env` з наступними змінними:

```env
BOT_TOKEN=your_telegram_bot_token
CHANNEL_ID=@your_channel
ALERTS_API_TOKEN=your_alerts_api_token
```

### 3. Запуск персоналізованого бота

```bash
python main_personalized.py
```

## 📋 Команди бота

### Основні команди

- `/start` - Почати роботу з ботом
- `/help` - Показати довідку
- `/settings` - Налаштувати підписки
- `/status` - Перевірити поточні налаштування

### Команди підписки

- `/subscribe alerts` - підписатися на тривоги
- `/subscribe news` - підписатися на новини
- `/subscribe memorial` - підписатися на меморіальні повідомлення
- `/subscribe all` - підписатися на все

### Команди відписки

- `/unsubscribe alerts` - відписатися від тривог
- `/unsubscribe news` - відписатися від новин
- `/unsubscribe memorial` - відписатися від меморіальних повідомлень
- `/unsubscribe all` - відписатися від всього

### Адміністративні команди

- `/stats` - Статистика користувачів

## 🎛️ Налаштування підписок

### Через команду /settings

1. Натисніть `/settings`
2. Використовуйте inline кнопки для перемикання підписок:
   - ✅ 🚨 Тривоги
   - ✅ 📰 Новини
   - ✅ 🕯️ Меморіальні
3. Натисніть "💾 Зберегти"

### Через команди

```bash
/subscribe alerts    # Підписатися на тривоги
/unsubscribe news    # Відписатися від новин
```

## 📊 База даних користувачів

Користувачі зберігаються в файлі `users.json`:

```json
{
  "123456789": {
    "user_id": 123456789,
    "username": "user123",
    "first_name": "User Name",
    "subscriptions": {
      "alerts": true,
      "news": false,
      "memorial": true
    },
    "created_at": "2024-01-01T12:00:00",
    "last_activity": "2024-01-01T12:00:00"
  }
}
```

## 🔧 Налаштування

### Типи підписок

- **alerts** - Повітряні тривоги
- **news** - Останні новини
- **memorial** - Меморіальні повідомлення

### За замовчуванням

Нові користувачі автоматично підписуються на всі типи повідомлень.

## 📈 Статистика

Команда `/stats` показує:
- Загальна кількість користувачів
- Кількість підписників на кожен тип повідомлень

## 🛠️ Розробка

### Додавання нового типу повідомлень

1. Додайте новий тип в `user_manager.py`:
```python
'subscriptions': {
    'alerts': True,
    'news': True,
    'memorial': True,
    'new_type': True  # Новий тип
}
```

2. Оновіть `personalized_bot.py`:
```python
sub_name = {
    'alerts': '🚨 Тривоги',
    'news': '📰 Новини',
    'memorial': '🕯️ Меморіальні',
    'new_type': '🆕 Новий тип'  # Додайте назву
}
```

3. Створіть метод для надсилання:
```python
async def send_new_type_to_users(self, message: str, user_ids: List[int]):
    return await self.send_personalized_message(
        user_ids=user_ids,
        message=message,
        subscription_type='new_type',
        parse_mode='HTML'
    )
```

## 🚨 Важливі примітки

- Бот автоматично додає користувачів при першому використанні команди `/start`
- Налаштування зберігаються автоматично
- При помилках надсилання повідомлень, бот продовжує роботу
- Всі дії користувачів логуються

## 📞 Підтримка

При виникненні проблем:
1. Перевірте логи бота
2. Переконайтеся, що всі залежності встановлені
3. Перевірте правильність токенів в `.env` файлі
